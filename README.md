# Petstore

Это мой проект для проверки API Petstore. Написан на Python, для тестов использовал pytest, а для запросов — requests.

## Что проверяется

В проекте 8 тестов:
- добавление питомца;
- получение питомца по id;
- изменение питомца;
- удаление питомца;
- получение остатков магазина;
- создание заказа;
- получение заказа по id;
- удаление заказа.

В тестах проверяю код ответа 200 и в некоторых тестах данные, которые вернул сервер: имя или id. В проверке остатков смотрю, что ответ пришёл в виде словаря.

## Файлы проекта

- base_request.py — общий класс для отправки GET, POST, PUT и DELETE запросов. Тут же указан адрес API.
- test_pet.py — тесты для питомцев.
- test_store.py — тесты для магазина и заказов.
- requirements.txt — библиотеки которые нужны для работы.
- test_results.png — скриншот с результатами запуска.
- test_results.md — результаты тестов в текстовом виде.
- README.md — описание проекта и как его запустить.

## Результат

На сохранённом скриншоте все 8 тестов прошли:

```text
8 passed in 12.22s
```

PASSED значит, что проверки в тесте выполнены успешно. При следующем запуске время может отличатся, так как запросы идут на внешний сервер.
